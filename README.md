# CN-Platform-Atlas

> 中国社媒平台全景图谱 × 私域搜索（让 AI 检索到搜索引擎搜不到的内容）

通用搜索引擎够不到中文互联网的大片"私域"：微信公众号、小红书笔记、知识星球、电商评价区……本仓库是一套**调研 + 系统设计知识库**，回答三个问题：

1. 中国社媒平台到底有哪些、谁跟谁像（全景与聚类图谱）
2. 每个平台 AI 工具（MCP / skill）的覆盖现状如何（逐平台对照）
3. 在聚合器之上怎么建一个"知道该去哪儿找、知道找到的够不够用"的路由层（概念设计与评测基准）

## 五条核心结论

1. 私域孤岛集中在：微信生态、小红书、抖音、知识星球、电商评价区、封闭垂直社区
2. MCP 覆盖极不均：小红书最厚（单项目 17k★），百度贴吧、虎扑、NGA、脉脉、喜马拉雅基本空白
3. **聚合器优于单平台**：Agent-Reach（109k★）、cn-scraper-mcp、reach-mcp、RSSHub 四件分层覆盖，胜过装十几个单平台 MCP
4. skill 生态全是"创作/运营"向，"检索/阅读"能力全部长在 MCP 侧
5. 按**可达性四层**选工具，不按平台选：公开可抓 → 登录态（本地 cookie）→ 强反爬（人过验证码）→ 桌面封闭（桌面自动化兜底）

## 路线图

1. **benchmark v0**：36 道私域题（六类意图 × 四可达层）+ 双基线实测（基线 A = LLM+通用搜索直答；基线 B = LLM 自持全部聚合 MCP 自由发挥）——用数据回答"私域路由的价值增量"
2. **路由器 v0**：形态由第 1 步数据决定
3. **意图分类器本地化**：小模型承担路由分类（Adaptive-RAG 已证可行）

详细设计见概念设计文档 §3（benchmark）与 §5（架构）。
